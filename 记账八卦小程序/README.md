# 记账 · 智能消费分析

基于命理八字的智能记账与消费分析 Web 应用。纯前端实现（HTML + CSS + JS），无需后端，数据存储于浏览器 `localStorage`。

## 功能概览

### 1. 记账模块
- **3D 圆柱体分类选择器**：9 个消费分类以可旋转悬浮圆柱体形式排列，拖动旋转选择，松手自动吸附
- 记录金额、分类、日期、备注
- 今日支出概览 + 消费记录列表（全部/本周/本月筛选）
- 数据持久化（localStorage）

### 2. 分析模块
- **分类占比环形图**（SVG donut chart）
- **近 14 天趋势柱状图**（SVG bar chart）
- **消费八卦分布图**：后天八卦方位排列，消费金额映射到 8 个卦象，高消费卦象自动发光高亮
- **分类排行**：按金额排序的消费明细
- 月度总支出、日均、最大单笔、环比上月

### 3. 建议模块
- **月度预算**：设置预算、进度条、已用/剩余
- **今日宜购**（需输入八字）：根据当天天干地支 + 大运 + 流年，结合五行相生相克，判断今日适合/忌讳购买哪些类别
- **命理消费八卦**：个人八卦图 + 八字五行分析 + 命宫解读
- **智能消费建议**：基于消费数据和命理的综合建议引擎

### 4. 命理模块（生辰八字 · 命宫）
- **八字排盘**：输入出生日期、时辰、性别 → 计算年/月/日/时四柱
- **命宫计算**：基于月支和时支推算命宫天干地支
- **五行分析**：统计八字五行分布，识别缺失/过旺
- **大运推算**：从月柱起排，阳年男/阴年女顺排，阳年女/阴年男逆排，起运岁数由出生日到最近节气天数 ÷ 3
- **流年**：当年天干地支

### 核心技术点

| 功能 | 实现方式 |
|------|----------|
| 3D 圆柱体 | CSS `transform-style: preserve-3d` + `perspective` + 拖动事件 |
| 八卦图 | SVG 动态生成：扇区路径 + 三爻符号 + 太极图 + 悬浮动画 |
| 八字计算 | 天干地支算法：年柱（立春分界）、月柱（五虎遁）、日柱（基准日推算）、时柱（五鼠遁） |
| 大运推算 | 月柱起排 + 节气计算起运岁数 + 顺逆排规则 |
| 今日宜购 | 日干五行 + 五行相生相克 → 宜购/忌购分类映射 |
| 数据存储 | `localStorage`（消费记录 + 预算 + 八字数据） |
| 内网穿透 | cpolar（Windows 服务，隧道指向 8090 端口） |

### 今日宜购判断逻辑

1. 计算当天日柱 → 日干五行（代表自己）
2. 计算当前大运五行（代表运势方向）
3. 计算流年五行（代表当年运势）
4. **宜购** = 同我者 + 生我者（五行相生）
5. **忌购** = 我克者 + 克我者（五行相克）
6. 大运/流年五行与日干相生则加分，相克则警示

## 使用方法

### 本地运行

```bash
# 方式1：直接启动
python srv.py

# 方式2：Python 内置服务器
python -m http.server 8090 --directory D:\1\demo
```

访问 `http://localhost:8090`

### 公网访问（cpolar 内网穿透）

1. 安装 cpolar：`D:\cploar\cpolar.exe`
2. 配置 authtoken：`cpolar authtoken <token>`
3. 配置隧道（`C:\Users\<user>\.cpolar\cpolar.yml`）：
   ```yaml
   tunnels:
     website:
       addr: "8090"
       proto: http
   ```
4. 启动服务：`net start cpolar`
5. 查看公网地址：日志中搜索 `Tunnel established at https://`

### 使用流程

1. **记账**：输入金额 → 拖动圆柱体选择分类 → 选日期 → 提交
2. **分析**：查看环形图、趋势图、八卦分布、分类排行
3. **建议**：
   - 设置月度预算
   - 输入出生日期/时辰/性别 → 八字排盘
   - 查看今日宜购建议
   - 查看命理消费八卦解读
   - 查看智能消费建议列表

## 技术约束

- 纯前端，无后端依赖
- 数据仅存于浏览器 localStorage（清除浏览器数据会丢失）
- 八字计算基于公历日期，节气数据为近似值
- 大运起运岁数为近似计算（精确值需完整节气表）
- cpolar 免费版隧道 URL 会变化，重启服务后需查看新地址

## 浏览器兼容

- Chrome / Edge / Firefox（需支持 CSS 3D transform）
- 移动端支持触摸拖动旋转圆柱体
